🧪 testgen-service 控制台

代码 / URL → 测试用例 → 执行验证

① 填写被测对象

先点「扫描代码目录」列出文件，勾选要生成用例的文件/目录；不勾选则「生成用例」时全量生成。配合「生成模式」可进一步选择全量或增量。
点击「扫描代码目录」加载文件清单（基于上方「代码目录」字段）
增量模式仅对 diff 范围内代码生成测试点；需提供 git 仓库地址（非本地目录）以计算变更集。
提示：只填「代码目录」= 纯代码生成；只填「被测地址+账号」= 浏览器自动发现页面/接口生成。执行验证默认只读（不污染被测环境），勾下方可放行写/真实点击。
使用说明 / 安全说明

流程：① 填被测对象 → ②「生成用例」(异步，右下看进度) → ③ 生成完自动拿到项目ID → ④「执行验证」(可选) → ⑤「查看报告」。

真实调用：本控制台跑在你本机，浏览器发现与点击使用你电脑的真实网络，可真实访问内网/线上目标。

凭证安全：账号/密码/动态口令仅随本次请求发出，服务端不回显、不落库、不写入产物（平台设计如此）。请在本机受信任环境使用。

仓库配置：「代码仓库」菜单可保存常用仓库地址并测试连通性；连接测试用本机 git 凭据（平台不存密码）。
