## 一、全链路分段（S0 → S7）

```
S0 取码 / 给地址        「拿到被测对象」——代码目录 或 测试地址+账号
      ↓
S1 项目登记 + 代码扫描   upsert_project → scan → SourceFile 索引
      ↓
S2 功能点提取 (FP)       api / page / component / business（+ 运行时 UI 功能点并入）
      ↓
S3 差异打标 (全量/更新)   diff 基线对比 → 每个 FP 打「全量」或「更新」
      ↓
S4 测试点展开 (TP)       正常 / 异常 / 安全 / 边界（+ PRD 派生的业务规则）
      ↓
S5 用例生成 (Case)       TP → Case 1:1，八要素 + UI 优先排序 + 运行时细节富化
======================= 以上为「生成测试用例」范围 =======================
S6 用例执行              接口层真实 HTTP / UI 层浏览器
S7 报告产出              执行结论、追溯、趋势、导出
```

> **一句话现状**：S0–S5 **两条流程都能端到端出用例了**（A1/A2/A3 的成果）；
> 剩下的问题集中在**「生成得准不准」**（S3 静默降级、S2/S5 重复计数）与**「出线之后」**（S6 持久化 / S7 报告）。

### 9.2 F5 判定口径 v1.1（唯一真值：`engine/fp_merge.py` 模块 docstring）

1. **层类型对齐**：`api` 用 `METHOD + 归一化路径`；`page` 与 `ui` 同族；

`<Route element>`）作为唯一权威来源，属可选增强。

### 10.3 四条关键设计决定（为什么这么做）

1. **两张表、两种粒度**：`runs` 逐条（每批 N 行）承载「这条用例结论是什么」，
   `run_batches` 逐批（每批 1 行）承载「这一轮跑完没有 / 状态分布如何」。
   挤进一张表会让「0 条用例的批次」无处可记，也会让聚合查询退化成扫全表。legacy 同样分两张表。
2. **落库放在 `stage_persist`，且必须在 `reconcile_cases` 之后**：执行是对账前发生的，
   但 `cases` 行要等对账才就位——顺序反了，首次运行会「无处回填 `last_result`」。
   所有 DB 写入集中一处，天然共享一个事务。
3. **只写 `cases.last_result`，绝不改 `cases.status`**：生命周期（generated/updated/obsolete）与
   执行结论（pass/fail/skipped）是两套语义；混写会让「重新生成用例」把执行结论误当生命周期读取。
4. **宁可少写，也不写脏**：无批次号 = 本次没有执行 → 什么都不写（不留孤儿行）；
   同 `batch_id` 重跑**先清后写**（幂等）；执行基础设施失败也留一个 `state=failed` 的批次，
   让「开关开了却什么都没发生」不再可能。
   ⚠️ 踩过的坑：批次级错误文案若也叫 `error`，会与汇总**计数** `error` 同名互相覆盖 →
   文案键定为 `batch_error`（最隐蔽的一类「数据看着对其实错」）。

### 11.2 四条关键设计决定（为什么这么做）

1. **报告是 DB 事实的纯函数，且不新建 `reports` 表**：取数（`store.report_snapshot`）→
   计算（`engine/report`）→ 渲染（`output/report_writer`）三段严格分层。同一份数据任意时刻
   重算，结论一致（用 `test_report_is_reproducible_from_db` 锁死）。
   legacy `test-accel` 需要 `reports` 表，是因为它把执行明细只存进报告 JSON；本服务的明细
   已在 `runs`，报告随时可重算——**多一张报告表 = 多一个会与 `runs` 漂移的第二真值源**。
2. **通过率口径 `pass / (pass + fail)`，无判定类结论返回 `None` 而非 `0`**：`0` 会被误读成
   「全部失败」，而事实往往是「一条都没真正跑」（全 skipped / 环境态）。`skipped` 不计入分母，
   但**必须出现在摘要与要点里**——否则「执行器没跑」会被读者当成「全绿」。
3. **不粉饰**：UI 层因 F13 未实现而 skipped、写操作未放行、非 HTTP 来源，一律在摘要要点中
   点名原因（`跳过 N 条**不等于通过**：…`），并给出补跑入口。
4. **导出格式先做 json/md/html，PDF/Word/Excel 缓做**：前三种零新依赖（stdlib + `html.escape`）；
   后三种需要 reportlab / python-docx / openpyxl，按可选依赖扩展 `ReportFormat` 即可，不阻塞主线。
